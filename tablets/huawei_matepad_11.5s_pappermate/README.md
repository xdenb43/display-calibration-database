# Huawei MatePad 11.5s Pappermate (TGR-W09) 

Huawei MatePad 11.5S PaperMatte features an **IPS LCD display with a 2800 × 1840 resolution, P3 wide color gamut and a PaperMatte anti-glare display surface.**
Although IPS LCD displays generally do not use emissive pixels like OLED, **display luminance, viewing conditions and brightness modulation may still affect visual comfort** during prolonged use.

Settings optimized for **long-term visual comfort, readability and stable image reproduction** while maintaining natural color reproduction and maximum available display clarity.

Official product page: <https://consumer.huawei.com/ru/tablets/matepad-11-5-s/specs/>

## Daily Use Configuration   

The priority here is: **long-term visual comfort → readability → luminance control → natural and stable image reproduction → other parameters.**  

### Recommended System Settings (Eye Comfort + Work + Drawing)

| Parameter                                    | Value                            | Reason                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brightness (Яркость)                         | Auto (Авто)                      | Automatically adapts display luminance to ambient lighting, helping avoid unnecessarily high or low brightness while maintaining appropriate readability. This is particularly useful for a tablet used in changing lighting conditions.                                                                                                                                                                                                     |
| Dark Mode (Тёмный режим)                     | OFF — Light Mode (Светлый режим) | Dark text on a light background generally provides better fine-text legibility and is preferable for prolonged reading and work when readability is the primary goal.                                                                                                                                                                                                                                                                        |
| Eye Comfort / Eye Protection (Защита зрения) | OFF (Выкл.)                      | Keeps the display at its normal color balance without applying a permanent blue-light-reducing shift. This is particularly appropriate when accurate and stable color perception is important for drawing and other visual work.                                                                                                                                                                                                             |
| Font Size (Размер текста)                    | Default (Обычный)                | Preserves the intended interface geometry while providing sufficient text size without unnecessary scaling. The ~291 ppi display provides high text clarity at the default size.                                                                                                                                                                                                                                                             |
| Font Weight (Жирность текста)                | Default (Обычная)                | Maintains the intended text rendering and avoids unnecessarily heavy strokes. Default weight provides a good balance between readability and visual simplicity.                                                                                                                                                                                                                                                                              |
| Natural Tone (Естественный тон)              | OFF (Выкл.)                      | Keeps the white point and color reproduction stable rather than dynamically changing color temperature according to ambient lighting. This is preferable for a device frequently used for **drawing and color-sensitive work**, where consistent color appearance is more important than automatic adaptation. Huawei confirms that Natural Tone dynamically changes color temperature according to ambient lighting. ([Huawei Consumer][1]) |
| Color Mode (Цвета)                           | Normal (Обычный)                 | Provides natural color tones without artificially increasing saturation. Huawei specifically recommends Normal mode as easier on the eyes, while the display already supports the wide P3 gamut. This is also preferable for drawing because Vivid mode can make colors appear unnecessarily saturated. ([Huawei Consumer][1])                                                                                                               |
| Color Temperature (Цветовая температура)     | Default (По умолчанию)           | Provides the most neutral and predictable starting point for color reproduction. Huawei states that Default and Warm are easier on the eyes; Default is preferable here because the tablet is also used for drawing and color-sensitive work, where an intentionally warm white point can distort color perception. ([Huawei Consumer][1])                                                                                                   |
| Smart Resolution (Умное разрешение)          | ON (Вкл.)                        | Unlike the MatePad 10.4, you report that the TGR-W09 remains smooth with Smart Resolution enabled. Since there is no observed responsiveness penalty, keeping it ON allows the system to manage rendering dynamically without a demonstrated readability or comfort disadvantage.                                                                                                                                                            |
| Refresh Rate (Частота обновления экрана)     | Dynamic (Динамическая)           | Provides adaptive refresh-rate behavior up to 144 Hz, balancing smooth scrolling, pen interaction and system responsiveness with power consumption. For a tablet used both for work and drawing, Dynamic is preferable to permanently forcing either 144 Hz or 60 Hz. Huawei specifies a 30–144 Hz adaptive refresh range for this display. ([Huawei Consumer][2])                                                                           |
