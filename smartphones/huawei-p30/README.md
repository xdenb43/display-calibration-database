# Huawei P30 (ELE-L29) 

Huawei P30 features an OLED display with a wide DCI-P3 color gamut and integrated eye comfort features.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  
  
Settings optimized for visual comfort while maintaining natural color reproduction and maximum display clarity.  

Official product page:  <https://consumer.huawei.com/qa/phones/p302/>

## Calibration  

The priority here is: **readability → absence of visual strain → luminance control → other parameters.**  

### Recommended System Settings (Eye Comfort)

| Parameter                                        | Value                                | Reason                                                                                                                                                                                         |
| ------------------------------------------------ | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Brightness (Яркость)**                         | **Auto (Авто)**                      | Automatically adapts display luminance to ambient lighting, helping avoid unnecessarily high or low brightness and maintaining a more appropriate luminance level for the viewing environment. |
| **Dark Mode (Тёмный режим)**                     | **OFF — Light Mode (Светлый режим)** | Dark text on a light background is subjectively easier for you to read and causes less perceived strain. Positive polarity generally provides better fine-text legibility.                     |
| **Eye Comfort / Eye Protection (Защита зрения)** | **Off (Выкл.)**                      | Keeps the display at a neutral white point without unnecessary spectral shifting. A warmer color profile is not inherently required for eye comfort during normal use.                         |
| **Flicker Reduction (Снижение мерцания)**        | **On (Вкл.)**                        | Reduces brightness modulation and is therefore preferable for minimizing potential discomfort from OLED flicker.                                                                               |
| **Font Size (Размер текста)**                    | **Default (По умолчанию)**           | Preserves the intended interface geometry while providing sufficient text size without unnecessary scaling.                                                                                    |
| **Font Weight (Жирность текста)**                | **+1 step (+1 деление)**             | The default font is subjectively too thin and appears excessively sharp. One additional weight step improves stroke visibility and readability without making the text excessively bold.       |
| **Color Mode (Цвета)**                           | **Normal (Обычные)**                 | Provides neutral color reproduction without artificially increasing saturation or visual stimulation. This is appropriate for the P30's wide DCI-P3 gamut OLED display.                        |
| **Color Temperature (Цветовая температура)**     | **Default (По умолчанию)**           | Maintains a neutral white point without unnecessary spectral shifting. There is no sufficient basis to prefer a permanently warmer or cooler setting solely for eye comfort.                   |
| **Screen Resolution (Разрешение экрана)**        | **High (Высокое)**                   | Preserves the native 2340 × 1080 resolution and maximum text and fine-detail clarity at approximately 422 ppi. Lowering the resolution provides no clear visual-comfort advantage.             |
