# Huawei P30 (ELE-L29) 

Huawei P30 features an OLED display with a wide DCI-P3 color gamut and integrated eye comfort features.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  
  
Settings optimized for visual comfort while maintaining natural color reproduction and maximum display clarity.  

Official product page:  <https://consumer.huawei.com/qa/phones/p302/>

## Calibration  

The priority here is: **readability → absence of visual strain → luminance control → other parameters.**  

### Recommended System Settings (Eye Comfort)

| Parameter                                        | Value                                | Reason                                                                                                                                                                                                                                                  |
| ------------------------------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dark Mode (Тёмный режим)**                     | **OFF — Light Mode (Светлый режим)** | Dark text on a light background is subjectively easier for you to read and causes less perceived strain around the bridge of the nose. Positive polarity generally provides better legibility of fine text.                                             |
| **Eye Comfort / Eye Protection (Защита зрения)** | **Off (Выкл.)**                      | Keeps the display at a neutral white point without unnecessary spectral shifting. A warmer color profile is not inherently required for eye comfort during normal daytime use.                                                                          |
| **Flicker Reduction (Снижение мерцания)**        | **On (Вкл.)**                        | Reduces brightness modulation and is therefore preferable for minimizing potential discomfort from OLED flicker. The P30 uses an OLED panel, so keeping this function enabled is the conservative choice for flicker-sensitive use.                     |
| **Auto Brightness (Автояркость)**                | **On (Вкл.)**                        | Automatically adapts display luminance to ambient lighting, helping avoid unnecessarily high or low brightness and maintaining a more appropriate luminance level for the viewing environment.                                                          |
| **Color Mode (Цветовой режим)**                  | **Normal (Обычный)**                 | The P30 has a wide DCI-P3 color gamut. Normal mode avoids artificially boosted saturation and provides a more neutral, restrained image that is preferable for prolonged viewing.                                                                       |
| **Color Temperature (Цветовая температура)**     | **Default (По умолчанию)**           | Maintains a neutral white point without unnecessary spectral shifting. There is no sufficient basis to prefer a permanently warmer or cooler setting solely for eye comfort.                                                                            |
| **Screen Resolution (Разрешение экрана)**        | **High (Высокое)**                   | Uses the native 2340 × 1080 resolution and preserves maximum text and fine-detail clarity at approximately 422 ppi. Lowering the resolution provides no advantage for visual comfort when maximum text clarity is desired.                              |
| **Font Weight (Жирность текста)**                | **+1 step (+1 деление)**             | The default font is subjectively too thin and produces excessively sharp-looking text for you. A single step increases stroke width enough to improve readability and reduce the harsh, razor-thin appearance without making the text excessively bold. |
