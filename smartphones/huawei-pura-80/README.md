# Huawei Pura 80 (HED-LX9) 

Huawei Pura 80 features an OLED display with integrated eye comfort technologies.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  

Calibration/Settings optimized for visual comfort while maintaining natural color reproduction.

Official product page:  <https://consumer.huawei.com/ru/phones/pura80/>

## Calibration  

The priority here is: **readability → absence of visual strain → luminance control → other parameters.**  

### Recommended System Settings (Eye Comfort)

| Parameter                                        | Value                                                                | Reason                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------ | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dark Mode (Тёмный режим)**                     | **OFF — Light Mode (Светлый режим)**                                 | Dark text on a light background is subjectively easier for you to read and causes less perceived strain around the bridge of the nose. Positive polarity generally provides better fine-text legibility.                                                                               |
| **Eye Comfort / Eye Protection (Защита зрения)** | **Off (Выкл.)**                                                      | Keeps the display at a neutral white point without unnecessary spectral shifting. A warmer color profile is not inherently required for eye comfort during normal use.                                                                                                                 |
| **Flicker Reduction (Снижение мерцания)**        | **On (Вкл.)**                                                        | Reduces brightness modulation and is therefore preferable for minimizing potential discomfort from OLED flicker.                                                                                                                                                                       |
| **Font Size (Размер текста)**                    | **Default (По умолчанию)**                                           | Preserves the intended interface geometry while providing sufficient text size without unnecessary scaling.                                                                                                                                                                            |
| **Font Weight (Жирность текста)**                | **Default (По умолчанию)**                                           | On Light Mode, dark text already has strong contrast. Increasing the weight made the text appear excessively bold and less comfortable, while Default noticeably improved readability for you.                                                                                         |
| **Color Mode (Цвета)**                           | **Normal (Обычные)**                                                 | Provides neutral color reproduction without artificially increasing saturation or visual stimulation. This is appropriate for the Pura 80's wide-gamut OLED display.                                                                                                                   |
| **Color Temperature (Цветовая температура)**     | **Default (По умолчанию)**                                           | Maintains a neutral white point without unnecessary spectral shifting. There is no sufficient basis to prefer a permanently warmer or cooler setting solely for eye comfort.                                                                                                           |
| **Smart Resolution (Умное разрешение)**          | **Off (Выкл.)**                                                      | Preserves maximum text and fine-detail clarity at the native 2760 × 1256 resolution. Adaptive resolution reduction provides no clear visual-comfort advantage for your use case.                                                                                                       |
| **Refresh Rate (Частота обновления)**            | **High / 120 Hz — Recommended**; **Standard / 60 Hz — Power Saving** | Fixed 120 Hz provides stable frame timing during scrolling and avoids adaptive refresh-rate transitions. You experienced noticeably better comfort with fixed 120 Hz than with Dynamic mode. Fixed 60 Hz is also comfortable and can be used when battery life is prioritized. |
