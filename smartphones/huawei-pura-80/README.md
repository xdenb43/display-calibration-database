# Huawei Pura 80 (HED-LX9) 

Huawei Pura 80 features an OLED display with integrated eye comfort technologies.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  

Calibration/Settings optimized for visual comfort while maintaining natural color reproduction.

Official product page:  <https://consumer.huawei.com/ru/phones/pura80/>

## Calibration  

The priority here is: ** readability → absence of visual strain → luminance control → other parameters.**  

### Recommended System Settings (Eye Comfort)

| Parameter                                                         | Value                                | Reason                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dark Mode (Тёмный режим)**                                      | **OFF — Light Mode (Светлый режим)** | Dark text on a light background is subjectively easier for you to read and causes less perceived strain around the bridge of the nose. Positive polarity generally provides better legibility of fine text. The brightness of the light background should therefore be kept moderate to compensate for the larger luminous area of the OLED display. |
| **Microsoft SwiftKey Theme (Тема клавиатуры Microsoft SwiftKey)** | **Light**                            | Keeping the keyboard consistent with Light Mode preserves the same positive polarity throughout the interface and avoids abrupt transitions between light and dark areas while typing.                                                                                                                                                               |
| **Refresh Rate (Частота обновления)**                             | **Dynamic (Динамическая)**           | The LTPO OLED can adapt its refresh rate across a wide range up to 120 Hz. Dynamic mode allows a high refresh rate during motion and scrolling while reducing it for static content.                                                                                                                                                                 |
| **Flicker Reduction (Снижение мерцания)**                         | **On (Вкл.)**                        | The Pura 80 uses an OLED display with PWM. Huawei states that Flicker Reduction is designed to reduce flicker, making it appropriate to keep enabled to minimize potential discomfort from brightness modulation.                                                                                                                                    |
| **Color Mode (Цветовой режим)**                                   | **Normal (Обычный)**                 | Provides neutral color reproduction without artificially increasing saturation or unnecessary visual stimulation.                                                                                                                                                                                                                                    |
| **Color Temperature (Цветовая температура)**                      | **Default (По умолчанию)**           | There is no sufficient physical basis for permanently shifting the white point toward either warmer or cooler tones solely for eye comfort. The neutral setting is the most universal choice.                                                                                                                                                        |
| **Auto Brightness (Автояркость)**                                 | **On (Вкл.)**                        | Automatically adapting brightness to ambient lighting helps avoid both excessive luminance and an excessively dim image that could require additional visual effort for reading.                                                                                                                                                                     |
| **Smart Resolution (Умное разрешение)**                           | **Off (Выкл.)**                      | Preserves maximum text and fine-detail clarity at the native 2760 × 1256 resolution. This is preferable for reading compared with adaptive resolution reduction.                                                                                                                                                                                     |
| **Font Weight (Жирность текста)**                                 | **Default / 0**                      | Dark text on a light background already has strong luminance contrast. Increasing font weight substantially increases the visual mass of the characters and can make small text appear overly bold, reducing letter-shape clarity rather than improving readability.                                                                                 |
| **Font Size (Размер текста)**                                     | **Default (По умолчанию)**           | If the text is already comfortably readable, there is no need to increase the interface scale. This preserves the intended UI geometry and high information density.                                                                                                                                                                                 |
| **Eye Comfort / Eye Protection (Защита зрения)**                  | **Off (Выкл.)**                      | Permanently shifting the color temperature is not inherently necessary for eye protection. Keeping a neutral white point better supports natural text rendering and readability.                                                                                                                                                                     |
| **Vivid Color Mode (Яркие цвета)**                                | **Off (Выкл.)**                      | Avoids artificially increased saturation and maintains a more neutral and visually restrained image.                                                                                                                                                                                                                                                 |
