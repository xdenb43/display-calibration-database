# Huawei Pura 80 (HED-LX9) 

Huawei Pura 80 features an OLED display with integrated eye comfort technologies.  
Although OLED panels deliver excellent image quality, they **may increase eye fatigue** for some users during prolonged use.  

Calibration/Settings optimized for visual comfort while maintaining natural color reproduction.

Official product page:  <https://consumer.huawei.com/ru/phones/pura80/>

## Calibration  

The priority here is: **readability → absence of visual strain → luminance control → other parameters.**  

### Recommended System Settings (Eye Comfort)

| Parameter                                                         | Value                                                                | Reason                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dark Mode (Тёмный режим)**                                      | **OFF — Light Mode (Светлый режим)**                                 | Dark text on a light background is subjectively easier for you to read and causes less perceived strain around the bridge of the nose. Positive polarity generally provides better legibility of fine text.                                                                                                                       |
| **Microsoft SwiftKey Theme (Тема клавиатуры Microsoft SwiftKey)** | **Light**                                                            | Keeps the keyboard consistent with Light Mode and preserves the same positive polarity throughout the interface.                                                                                                                                                                                                                  |
| **Refresh Rate (Частота обновления)**                             | **High / 120 Hz — Recommended**; **Standard / 60 Hz — Power Saving** | Fixed 120 Hz provides stable frame timing during scrolling and avoids adaptive refresh-rate transitions. Since you experienced noticeably better comfort with fixed 120 Hz than with Dynamic mode, it is recommended for visual comfort. Fixed 60 Hz is also acceptable and can be used when battery life is prioritized. |
| **Flicker Reduction (Снижение мерцания)**                         | **On (Вкл.)**                                                        | Reduces the effect of brightness modulation and is therefore preferable for minimizing potential discomfort from OLED flicker.                                                                                                                                                                                                    |
| **Color Mode (Цветовой режим)**                                   | **Normal (Обычный)**                                                 | Provides neutral color reproduction without artificially increasing saturation or visual stimulation.                                                                                                                                                                                                                             |
| **Color Temperature (Цветовая температура)**                      | **Default (По умолчанию)**                                           | Avoids unnecessary spectral shifting and maintains a neutral white point.                                                                                                                                                                                                                                                         |
| **Auto Brightness (Автояркость)**                                 | **On (Вкл.)**                                                        | Adapts display luminance to ambient lighting, helping avoid unnecessarily high or low brightness.                                                                                                                                                                                                                                 |
| **Smart Resolution (Умное разрешение)**                           | **Off (Выкл.)**                                                      | Preserves maximum text and fine-detail clarity at the native 2760 × 1256 resolution.                                                                                                                                                                                                                                              |
| **Font Weight (Жирность текста)**                                 | **Default (По умолчанию)**                                           | On Light Mode, dark text already has strong contrast. Increasing the weight made the text appear excessively bold and less comfortable, while Default noticeably improved readability for you.                                                                                                                                    |
| **Font Size (Размер текста)**                                     | **Default (По умолчанию)**                                           | Maintains the intended interface geometry while providing sufficient text size without unnecessary scaling.                                                                                                                                                                                                                       |
| **Eye Comfort / Eye Protection (Защита зрения)**                  | **Off (Выкл.)**                                                      | Avoids unnecessary spectral shifting and preserves a neutral white point.                                                                                                                                                                                                                                                         |
| **Vivid Color Mode (Яркие цвета)**                                | **Off (Выкл.)**                                                      | Avoids artificially increased saturation and maintains a more neutral, visually restrained image.                                                                                                                                                                                                                                 |
